The GPS's own excuse for sending the driver down the wrong road: one line, 123 characters, pure-stdlib Python. The map swore a cul-de-sac was a shortcut to a wedding, and the GPS does not argue with maps — it just drives into lakes for them.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
```

This writes the excuse to `output/entry.txt`.
